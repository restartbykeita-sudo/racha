# RESTART RACHA ISLAND HYBRID — ระบบสมัคร

เว็บสมัครแข่งขัน ชำระเต็มหรือผ่อน 3 งวด และหลังบ้านตรวจสลิป สำหรับรีโป `restartbykeita-sudo/racha` โดยเฉพาะ

## โครงสร้าง

- `site/` หน้าเว็บที่เผยแพร่ด้วย GitHub Pages: `index.html` สำหรับผู้สมัคร และ `admin.html` สำหรับเจ้าหน้าที่
- `supabase/migrations/` โครงสร้างข้อมูลที่ติดตั้งแล้วใน Supabase โปรเจกต์ `tnvwdseomwzosjeemapd`
- `supabase/functions/registration-api/` API ที่ติดตั้งแล้วในโปรเจกต์เดียวกัน
- `.github/workflows/pages.yml` เผยแพร่เฉพาะ `site/` เมื่อมีการ push เข้า `main` หลังตั้งค่า Pages source เป็น GitHub Actions

ไฟล์ `site/config.js` มีเฉพาะ publishable key ซึ่งใช้บนเว็บได้ ไม่มี service-role key ในรีโป

## สถานะก่อนเปิดรับสมัครจริง

- Supabase มี 5 แพ็กเกจ 7 ไซซ์เสื้อ พื้นที่สลิปแบบ private และ API `registration-api` แล้ว
- กำหนดเปิดรับสมัคร 28 กันยายน 2569 เวลา 12:00 น. ตามเวลาไทย; ผ่อน 3,000 + 2,000 + ยอดที่เหลือ โดยงวด 2/3 ครบกำหนด 15/31 ตุลาคม
- ยังไม่มีบัญชีใน `rrih_admin_users` จึงยังไม่มีคนเข้าสู่หน้าแอดมินเพื่อตรวจสลิป
- แพ็กเกจ 14,000 บาทตั้งไว้เป็นผู้แข่งขัน 2 คนตามข้อความ “1 ห้อง 2 ผู้แข่งขัน”; ข้อความต้นทางยังมีคำว่า “แข่งขัน 1 ท่าน” จึงต้องยืนยันก่อนเปิดจริง
- ข้อมูล PromptPay มาจากรายละเอียดเดิม ส่วนเลขบัญชีธนาคารยังว่าง หน้าเว็บซ่อนช่องที่ไม่มีข้อมูล
- ยังไม่มีข้อความแจ้งการใช้ข้อมูลส่วนบุคคลฉบับสาธารณะและช่องทางติดต่อกรณีรหัสยืนยันสูญหาย

ผู้สมัครค้นใบเดิมด้วยบัตร/Passport ของผู้แข่งขันคนใดก็ได้ **พร้อมรหัสยืนยันที่แสดงเมื่อสมัคร** เพื่อป้องกันการเปิดข้อมูลด้วยเลขบัตรอย่างเดียว สลิปทุกครั้งยังเป็นสถานะรอตรวจจนเจ้าหน้าที่อนุมัติ

## การเผยแพร่

รีโปนี้เริ่มจากรีโปว่าง จึงวางเว็บไว้ที่ `site/` เป็นหน้าแรกของ GitHub Pages หลังเลือก **Settings → Pages → Source: GitHub Actions** และ workflow สำเร็จ หน้าเว็บจะอยู่ใต้ `/racha/` และหน้าแอดมินอยู่ใต้ `/racha/admin.html` ตรวจ URL จริงจากผล deploy ก่อนประชาสัมพันธ์

ก่อนรับข้อมูลจริง ให้เพิ่มผู้ใช้ที่ตั้งใจเป็นเจ้าหน้าที่ใน Supabase Auth และผูก UUID นั้นกับ `public.rrih_admin_users` ตรวจบัญชีรับเงิน รายละเอียดแพ็กเกจ และข้อความแจ้งการใช้ข้อมูลให้ครบ แล้วทดลองสมัครและอนุมัติสลิปผ่านเว็บจริง
